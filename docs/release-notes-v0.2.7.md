# Glider v0.2.7

Update now: Glider shows a "Glider is ready" notice once the update has downloaded; choose **Restart**, or it installs when you quit Glider. Or run `Glider-win-Setup.exe` and choose **Update**.

## Changed

- **The Store sits on Mica too.** On Windows 11 with the dark theme, the Store tab now has the same background as the rest of Glider instead of Epic's flat black. Only colours change; the Store itself works exactly as before. With the light theme it keeps Epic's own dark page.
- **Game art is easier to see.** The dark shade over a game's art on its page is much lighter; the title and buttons stay as readable as before.

## Fixed

- **Opening a game from Home no longer jumps.** Clicking a card under "Continue playing" briefly showed a different, zoomed-in picture while it grew into the game page. It now grows from the picture you clicked.
- **Clean corners on game art.** A thin bright line showed along the rounded corners of the art on a game's page.
