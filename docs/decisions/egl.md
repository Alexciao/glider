# EGL coexistence decisions

One line of reasoning per decision. Details: `docs/egl.md`.

- **One-time `legendary import` + Glider drift checks, never continuous `egl-sync`**: egl-sync crashes when EGL is absent, flaps on InstallTags, and deletes EGL files on uninstall.
- **`.item` is the primary source and `LauncherInstalled.dat` the secondary one**: the `.item` has everything (guid, size, flags); `.dat` only adds installs whose item is missing.
- **Candidates are deduped by normalized path (case, slashes, trailing separators, `\\?\`)**: EGL and users spell the same folder many ways, and Windows treats them as one.
- **Candidate id = `egl-` + SHA-256(normalized path)[:16 hex]**: stable across scans, restarts and spellings, with no state to persist.
- **Stale manifests are reported (`IsStale`), not hidden**: the UI can explain "EGL thinks Fortnite is at X".
- **Tolerant parsing (BOM, UTF-16, comments, trailing commas, wrong types); bad files are logged and skipped**: one corrupt item must not hide the real install.
- **Write paths read items strictly (a locked `.item` fails the write)**: skipping it could create a second `.item` for the same install.
- **The changelist number is authoritative for version order; otherwise compare numbers component-wise; anything else is `Unreconcilable`**: hotfix CLs can carry older labels, and guessing wrong would trigger a needless re-download or a bad write-back.
- **Ambiguity (guid mismatch, incomplete flag, duplicate items, unorderable versions) → `Unreconcilable` → quick verify**: a verify is cheap next to a wrong download or a corrupted EGL record.
- **Write-back is a literal port of `EGLManifest.from_json`/`to_json` plus `from_lgd_game`'s overrides**: EGL demonstrably accepts Legendary's items, so byte-identical output inherits that track record.
- **Merge into the existing `.item` (keep EGL-only keys) instead of Legendary's from-scratch export**: it loses nothing EGL may rely on (required by the module spec).
- **Fields Glider doesn't track (BaseURLs, LaunchCommand, bCanRunOffline, DisplayName, folder name, OwnershipToken) keep EGL's values**: EGL's values are accurate, and inventing them is not.
- **An empty InstallTags list from Glider keeps EGL's tags**: Legendary imports have no tags, and writing `[]` could change EGL's content selection.
- **Drop `ManifestHash` when the version changes**: it would describe the replaced manifest, and Legendary-written items never carry it.
- **EGL's existing guid and file name for the folder win over the caller's guid**: two items for one folder make EGL list the game twice.
- **Output uses CRLF line endings**: that is what Python's text mode writes on Windows, the only platform where Legendary writes EGL files.
- **Goldens are generated by running Legendary's own code (`tools/egl-golden`)**: this proves format parity instead of asserting our own reading of it.
- **Refuse to write without Legendary's manifest for the new version**: an item that claims a version whose `.egstore` manifest is old makes EGL re-validate or re-download.
- **Backup every changed EGL file, keep the newest 20 sets, write a `backup-index.txt`**: any change can be undone by hand, and disk use stays bounded.
- **Atomic temp-in-same-dir + `File.Replace`, 5 lock retries at 200 ms, then a clear `FilesLocked`/`PermissionDenied`**: EGL never sees a half-written file, and the user gets an actionable message.
- **Roll back the files already committed when a later one fails**: EGL must never see a new `.manifest` next to an old `.item`.
- **Unchanged files aren't rewritten (and get no backup)**: repeated write-backs are free and quiet.
- **Patch `LauncherInstalled.dat` in place (only the two values), only when it already lists the install**: other tools read it, and a byte-surgical edit preserves EGL's formatting and encoding while never adding entries.
- **Non-ASCII in patched `.dat` values is written as `\uXXXX`**: valid JSON whether EGL reads the file as ANSI, UTF-8 or UTF-16.
- **Busy requires EGL running plus per-install evidence (incomplete flag, fresh `bps`/`Pending`, a fresh pending item)**: an open EGL is not a reason to block, and leftover staging from a closed or paused EGL is not either.
- **Staging counts as "fresh" within 3 minutes**: EGL writes staging continuously while downloading; older staging means paused or abandoned.
- **Wait = FileSystemWatcher wake-ups + a 2 s poll**: it reacts quickly to the evidence clearing without busy-looping, and still notices EGL exiting.
- **"Remove from Glider only" touches no EGL file, and even "delete files" leaves EGL's `.item`/`.egstore`**: never delete EGL's records; EGL handles its own uninstall.
- **The process lookup sits behind `IProcessProbe`**: tests fake EGL running or exiting without real processes.
- **v0.2: adoption carries install tags, re-import is forget+import in a job, readiness is per game with fixes**: see `## v0.2` in DECISIONS.md and "v0.2: migrating the whole library" in `docs/egl.md`.
