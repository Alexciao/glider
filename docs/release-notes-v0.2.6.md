# Glider v0.2.6

Update now: Glider 0.2.5 shows a "Glider is ready" notice once the update has downloaded; choose **Restart**, or it installs when you quit Glider. Or run `Glider-win-Setup.exe` and choose **Update**.

## Changed

- **More Mica.** On Windows 11 the whole window now sits on Mica, the content area included, as in Windows 11's own apps. When Windows turns Mica off (window in the background, transparency effects off, Battery Saver, Windows 10) Glider looks the same as before.

## Fixed

- **Create shortcut shows what it did.** The shortcut was created, but the menu never ticked it, so it looked like nothing happened and it couldn't be removed from the menu. The ticks now follow your shortcuts, a second click removes one, and a notice confirms each change.
- **Tooltips no longer hide behind the Store.** The hints on the left bar opened to the right, under the Store page. While the Store is open they now open below their button.
