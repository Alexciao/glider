# Screenshots

Generated by Playwright in `frontend/` (headless Chromium, Vite dev server, mock backend). Nothing here is hand-edited.

| Folder | What |
|---|---|
| `dark-solid-1280x800/`, `light-solid-1280x800/` | **Committed.** The README set, six screens each: `home`, `library-grid`, `game-page`, `downloads` (an install in progress), `onboarding-scan`, `settings`. Regenerate with `pnpm screenshots:readme`. |
| `surface-<theme>-<surface>/` | **Committed** for `mica-solid` (window inactive, transparency off, Battery Saver) and `win10`: `home-returning`, `game-installed`, `downloads-active`, `settings-downloads`, `dialog-install`, from `e2e/surfaces.spec.ts`, which sets what the host sets (`data-backdrop`, `data-surface`). `mica-active` is rendered but not committed. |
| `v0.2/` | **Committed.** Before/after pairs for the main fixes of the v0.2 UI review ([ui-review.md](../ui-review.md)). |
| `<theme>-<backdrop>-<WxH>/` | The full matrix, one PNG per state (about 130): `theme` = `dark` / `light`; `backdrop` = `solid` / `mica` (a blurred gradient "wallpaper" behind the translucent page); size = 1280×800 or 960×600. `pnpm screenshots` writes them; the two committed folders above are a subset of this output. Git-ignored except those two. |
| `break-ui/<mode>-<WxH>/` | Key screens with worst-case / empty / one / huge data (`src/dev/stress.ts`, `?data=worst`), including 960×540 (1080p at 200 % zoom). Git-ignored. |

Every state is defined once in `frontend/e2e/states.ts` and shared by the screenshot, accessibility, copy-dump and break-UI specs.

```sh
cd frontend
pnpm exec playwright install chromium   # once
pnpm screenshots:readme                 # the six committed screens, dark and light
pnpm screenshots                        # the whole matrix and break-UI (~8 min)
SHOT_ONLY=game,dialog SHOT_VARIANTS=dark-solid-1280x800 SHOT_OUT=/some/dir pnpm exec playwright test e2e/screenshots.spec.ts   # a slice, elsewhere
COPY_OUT=/some/dir pnpm exec playwright test e2e/copy-dump.spec.ts   # every visible string per state, as text
node e2e/tools/sheet.mjs --dir <variantDir> <outDir>   # contact sheets
node e2e/tools/audit-controls.mjs                      # heights, radii and icon sizes of every control per screen
```
